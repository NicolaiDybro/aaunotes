#### Methods
- Overloading, when multiple definitions for same method name
- Constructor, instance method (non-static) and class method (static)
- Parameters are called formal parameters. Arguments are called actual parameters

#### Initialization blocks ??
- functional code that runs when defining a class if static or creating an object if not static.
- is defined between curly brackets

#### Access modifier
- Public - Accessible from it self
- Private - Accessible from everywhere
- Protected - Accessible from package or decendants of class
